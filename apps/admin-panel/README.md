# Admin Panel

Next.js admin panel for the AI VPS Management System.

## Current Scope

This is the phase 5 foundation. It provides:

- App Router setup.
- TypeScript.
- Admin shell layout.
- Sidebar navigation.
- Dashboard foundation.
- API status page.
- Shared API client.

It does not yet provide auth, RBAC, CRUD, or agent chat.

## Install

```bash
npm install --no-audit --no-fund --ignore-scripts
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Environment

```text
NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000
```
