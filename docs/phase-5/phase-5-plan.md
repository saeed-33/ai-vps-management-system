# المرحلة الخامسة: Admin Panel Foundation

## الهدف

إنشاء أساس لوحة الإدارة كواجهة تشغيل فعلية للنظام.

هذه المرحلة لا تبني كل صفحات الإدارة، لكنها تضع الهيكل الذي ستبنى عليه:

- Dashboard.
- إدارة المستخدمين.
- إدارة السيرفرات.
- إدارة ملفات المراقبة.
- إدارة الوكلاء المتخصصين.
- إدارة المشكلات.
- إدارة التقارير.
- إدارة الأدوات والحلول المسموحة.
- إدارة الوثائق.
- المحادثة مع الوكيل.

## النطاق

داخل النطاق:

- إنشاء تطبيق Next.js داخل `apps/admin-panel`.
- استخدام TypeScript.
- إنشاء layout إداري ثابت.
- إنشاء sidebar عملي.
- إنشاء dashboard أولي.
- إنشاء صفحة حالة API.
- إنشاء API client للاتصال بالـ Backend.
- إنشاء بنية features أولية.
- توثيق التشغيل المحلي.

خارج النطاق حاليا:

- تسجيل دخول فعلي.
- RBAC في الواجهة.
- CRUD كامل.
- جداول بيانات متقدمة.
- ربط WebSocket أو streaming chat.
- تصميم نهائي لكل الصفحات.
- اختبارات E2E.
