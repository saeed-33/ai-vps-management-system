# خطة المرحلة السادسة عشرة: ربط إعدادات SSH بإدارة السيرفرات

## الهدف

نقل إعدادات SSH من متغيرات foundation فقط إلى إدارة السيرفرات، بحيث يمكن تعريف إعدادات SSH مؤقتا من لوحة الإدارة واستخدامها في وكيل المراقبة الدورية.

## النطاق

- إضافة نماذج SSH public/update للسيرفرات.
- إضافة endpoint لتحديث SSH access لسيرفر واحد.
- إخفاء كلمة المرور من كل الاستجابات.
- ربط periodic monitoring بإعدادات SSH المحفوظة مؤقتا.
- إضافة نموذج SSH في صفحة السيرفرات.
- إضافة اختبارات API.
- توثيق المرحلة.

## خارج النطاق

- تخزين دائم في PostgreSQL.
- تشفير secrets في قاعدة البيانات.
- اختبار اتصال SSH من الواجهة.
- إدارة عدة سيرفرات كاملة.
- تحليل مشكلات أو حلول.

## endpoint الجديد

```text
PUT /api/v1/servers/{server_id}/ssh-access
```

## ملاحظة أمنية

هذا تخزين مؤقت داخل ذاكرة API للتطوير فقط. لا يصلح للإنتاج قبل إضافة encrypted secrets storage أو secrets manager.
