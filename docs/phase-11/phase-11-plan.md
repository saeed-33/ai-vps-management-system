# خطة المرحلة الحادية عشرة: أساس إدارة الأدوات المسموحة

## الهدف

إضافة أساس عملي لإدارة الأدوات المسموحة التي يمكن للوكيل استخدامها لاحقا ضمن المراقبة والتحليل، مع فصل واضح بين أدوات القراءة وأي أدوات قد تغير حالة السيرفر.

## النطاق

- إضافة schemas للأدوات المسموحة.
- إضافة service foundation ببيانات fixture.
- إضافة endpoints لقائمة الأدوات وملخصها وتفاصيل أداة واحدة.
- إضافة صلاحية قراءة مستقلة `tools.read`.
- حماية endpoints بالمصادقة وصلاحية القراءة.
- إضافة صفحة `/allowed-tools` في لوحة الإدارة.
- ربط الصفحة بعميل API.
- توثيق المرحلة.

## خارج النطاق

- إنشاء أو تعديل أو حذف أدوات.
- تنفيذ أي أداة على سيرفر فعلي.
- ربط الأدوات بـ sandbox.
- اعتماد حلول أو تشغيل حلول.
- إدارة أسرار أو credentials للأدوات.

## endpoints المطلوبة

```text
GET /api/v1/allowed-tools
GET /api/v1/allowed-tools/summary
GET /api/v1/allowed-tools/{tool_id}
```

## قاعدة أمنية

إضافة أداة إلى قائمة الأدوات المسموحة لا تعني السماح بتنفيذ حلول. الأدوات في هذه المرحلة read-only ومخصصة لجمع الأدلة فقط. أي أداة mutating تحتاج سياسة منفصلة وموافقة لاحقة.
