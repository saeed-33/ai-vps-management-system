# Phase 29: Analysis Reports UX Redesign

## Objective

Improve the analysis reports presentation so each report can be inspected as a real diagnostic artifact instead of a small summary card.

## Required Work

- Replace the dense analysis report card grid.
- Add a master-detail layout.
- Let the user select one analysis report from a report list.
- Show the selected report with clear sections:
  - summary,
  - metadata,
  - monitoring profiles,
  - LLM enrichment,
  - findings,
  - next actions.
- Keep the page responsive on smaller screens.

## Out Of Scope

- Changing report generation.
- Changing LLM behavior.
- Adding chat.
