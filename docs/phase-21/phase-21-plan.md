# Phase 21: Server Management UX Improvement

## Goal

Improve the server management experience so adding servers and preparing SSH monitoring is clear and less error-prone.

## Required Work

- Make the add-server form more complete.
- Show whether a server is persisted in the database or only memory fallback.
- Make selected server state obvious.
- Pre-fill SSH fields from the selected server and existing SSH configuration.
- Show API error details instead of generic request failures.
- Improve layout responsiveness for server forms and rows.

## Out of Scope

- Backend schema changes.
- Report analysis.
- Secret encryption.
