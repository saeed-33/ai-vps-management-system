# خطة المرحلة الرابعة عشرة: وكيل المراقبة الدورية الفعلي

## الهدف

استكمال نطاق المراقبة الدورية بإضافة حزمة وكيل فعلية منفصلة داخل `apps/agent`، بحيث لا يبقى جمع تقارير المراقبة منطقيا داخل Control Plane API.

## النطاق

- إنشاء مشروع Python مستقل للوكيل.
- إضافة `PeriodicMonitoringAgent`.
- إضافة `ServerSubAgent`.
- إضافة collector read-only foundation.
- إضافة نماذج تقارير خاصة بالوكيل.
- ربط Backend API بحزمة الوكيل المحلية.
- إبقاء الـ API مسؤولا عن التحكم والجدولة والحفظ المؤقت فقط.
- إضافة اختبار مباشر للوكيل.

## خارج النطاق

- SSH إلى سيرفرات حقيقية.
- MCP runtime.
- Worker مستقل.
- تحليل مشكلات.
- تشغيل وكلاء متخصصين.
- حلول أو sandbox execution.

## معيار النجاح

- يمكن اختبار `apps/agent` منفردا.
- يستدعي الـ API `PeriodicMonitoringAgent`.
- تبقى endpoints الحالية كما هي.
- تبقى المخرجات تقارير مراقبة دورية فقط.
