# Phase 23: Periodic Monitoring UX Improvement

## Goal

Improve the periodic monitoring screen so reports are easy to inspect after running real server monitoring.

## Required Work

- Make cycle selection clearer.
- Improve scheduler controls and status display.
- Display reports as readable server cards.
- Display metrics as compact metric cards.
- Make failed reports visually obvious.
- Keep this phase limited to reporting and visibility, not analysis.

## Out of Scope

- Automated report analysis.
- Specialist agent activation.
- Solution generation.
