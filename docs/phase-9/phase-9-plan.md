# خطة المرحلة التاسعة: أساس إدارة ملفات المراقبة

## الهدف

إضافة أساس عملي لإدارة ملفات المراقبة من لوحة الإدارة وBackend API، بحيث تصبح ملفات المراقبة كيانا قابلا للعرض والفهم قبل الانتقال إلى CRUD وقاعدة البيانات.

## النطاق

- إضافة schemas لملفات المراقبة.
- إضافة service foundation ببيانات fixture مفصلة.
- إضافة endpoints لقائمة الملفات وملخصها وتفاصيل ملف واحد.
- حماية endpoints بالمصادقة وصلاحية `monitoring.read`.
- إضافة صفحة `/monitoring-profiles` في لوحة الإدارة.
- ربط الصفحة بعميل API.
- توثيق المرحلة.

## خارج النطاق

- إنشاء أو تعديل أو حذف ملفات مراقبة.
- ربط PostgreSQL.
- تشغيل مراقبة فعلية على السيرفرات.
- تشغيل وكلاء متخصصين.
- تنفيذ حلول أو أوامر على السيرفرات.

## endpoints المطلوبة

```text
GET /api/v1/monitoring-profiles
GET /api/v1/monitoring-profiles/summary
GET /api/v1/monitoring-profiles/{profile_id}
```

## تعريف مهم

ملفات المراقبة لا تعطي حكما نهائيا اعتمادا على العتبات وحدها. العتبات هي إشارات تحليل، وقد تكون القيمة المنخفضة مشكلة عند وجود أعراض مثل توقف workers أو نمو queues أو تدهور service-level behavior.
